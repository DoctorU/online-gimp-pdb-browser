# Repository Development Instructions

Apply these instructions when implementing code changes in this repository:

- Always work against an existing issue. If a request is not tied to an issue, ask the user to identify or create one before implementation.
- Always work on an issue-specific branch. Work directly on `main` only when the user explicitly authorizes it.
- Use Git worktrees when they are sensible and helpful, especially when multiple agents need isolated working copies.
- Always create a pull request for issue work so the changes can be reviewed.
